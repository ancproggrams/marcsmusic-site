## 1. SomaFM — San Francisco, California, United States / worldwide internet radio

### Public first-party routes

Reviewed official surfaces:

- Homepage: `https://somafm.com/`
- Contact page: `https://somafm.com/contact/`
- Submit Music page: `https://somafm.com/contact/submitmusic.html`

The official Submit Music page states that SomaFM supports commercial, independent, emerging and unsigned artists and attempts to listen to submitted music, although high volume means a response is not guaranteed.

SomaFM currently requires electronic delivery and no longer accepts physical CDs.

The canonical process is:

1. choose one currently accepting channel;
2. use only that channel's designated submission mailbox;
3. provide either a Bandcamp link with a YUM download code or a permissioned WeTransfer, Dropbox or comparable downloadable folder;
4. supply compliant broadcast-ready MP3 files and metadata;
5. do not send the same release to multiple music directors.

### Hard AI-provenance restriction

SomaFM states that it does not accept AI music submissions and gives Suno as an example. The network describes itself as human-centered.

This rule is stored as a strict eligibility knockout. A human reviewer must establish the complete creation and production provenance of the selected MarcsMusic release before any delivery. If the release falls within SomaFM's prohibition, it must not be submitted.

The reviewed page does not define every borderline case involving AI-assisted production. Uncertainty must be resolved conservatively rather than inferred away.

### File and delivery requirements

SomaFM publishes the following requirements:

- Bandcamp submissions must include a link and YUM download code;
- otherwise, use WeTransfer, Dropbox or a similar permissioned download service;
- share a downloadable link rather than a collaborative folder invitation;
- MP3 files must be 256 kbps or v0/highest-quality VBR at 44.1 kHz;
- WAV, AIFF and FLAC files are not accepted;
- 128 kbps MP3 files are not accepted;
- Facebook, SoundCloud, YouTube and Mixcloud files are not broadcast-ready submission formats;
- Haulix is not accepted because of spam problems;
- artist and track names must be correct in the metadata;
- include the album name, or `(Single)` when appropriate;
- include the artist website and email address in the comments field;
- set an accurate genre;
- the optional Grouping field may identify the intended channel;
- physical CDs are not accepted.

A reviewer must verify the actual exported files and embedded metadata rather than relying only on filenames or a streaming-page description.

### Capacity and routing boundary

Only channels listed on the current Submit Music page are accepting submissions. SomaFM states that other music directors are backlogged and recommends checking again later.

The broad `promosubmissions@somafm.com` group is also described as heavily backlogged. Backlog does not invalidate the authorized route, but it requires patience and makes repeated follow-up inappropriate.

SomaFM states that sending the same release to multiple music directors will cause the messages to be ignored. The queue therefore requires one-channel-only routing.

The official Contact page separately asks correspondents not to put addresses on mailing lists and warns that duplicate messages to multiple people may be rejected by the spam filter.
