# Toetsenbordkaarten

Vier kaarten. De eerste drie zijn de MasterDisaster-set van 29 september 2026, overgenomen uit de music-production skill. De vierde is de Meta Business Suite-kaart uit de plannersessie van 30 september 2026.

Verzin geen sneltoets die niet in het bijbehorende bestand staat.

| Kaart | Bestand | Wat erin staat |
|---|---|---|
| LUNA, custom set `MasterDisaster` | [lumen-keyboard-map.md](lumen-keyboard-map.md) | LUNA 3.0.0 build 4563, 182 fabriekscommando's. Twee extra bindingen: Nudge Left 1 Bar is `Ctrl+Opt+Left`, Nudge Right 1 Bar is `Ctrl+Opt+Right` |
| FL Studio 26.1.0.5294 | [keyboard-map.md](keyboard-map.md) | Transport, vensters, bewerken, channel rack en mixer, volgens de Image-Line-handleiding, met Command en Option op deze Mac |
| Controller | [lumen-midi-map.md](lumen-midi-map.md) | Indeling voor knoppen, pads en wielen zodra er een controller aangesloten is. LUNA heeft in deze build geen host-MIDI-map |
| Meta Business Suite | [meta-business-suite-toetsenbord.md](meta-business-suite-toetsenbord.md) | Planner van Instagram `marcsmusic_1`: adresbalk, cursor en benoemde menu's. Geen DAW-toetsen |

`Cmd+Space` is Spotlight. Die toets bereikt LUNA Record en FL Studio pause niet. In Business Suite gelden de Facebook-feedletters (`J`, `K`, `P`, `L`, `C`, `S`, `O`, `/`, `Q`, `?`) niet.

De bron van de LUNA-customset op de Mac is `~/Library/Application Support/Universal Audio/Custom Shortcuts/shortcuts.json`. Die set niet overschrijven.
